# primer-design-python

本地 DNA 引物设计与特异性评估服务。给定模板序列与设计参数，服务生成候选
引物对，计算关键理化性质，在参考序列库中评估非目标结合风险，并返回可复现
的排序结果。

## 运行

```bash
uv sync
uv run uvicorn main:app --host 127.0.0.1 --port 8000
# 数据目录（任务记录 + 参考库）默认 ./.primer_design_data，
# 可用环境变量 PRIMER_DESIGN_HOME 覆盖。
```

测试：`uv run pytest`

## API 概览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/health` | 健康检查 |
| POST | `/libraries/{name}/references` | 批量新增/更新参考序列（原子生效） |
| DELETE | `/libraries/{name}/references` | 批量删除参考序列 |
| GET | `/libraries/{name}` | 库版本与条目数 |
| POST | `/designs` | 提交设计任务（202，返回 `task_id`） |
| GET | `/designs/{task_id}` | 查询状态/进度/结果 |
| POST | `/designs/{task_id}/cancel` | 请求取消 |

### 设计参数（POST /designs）

| 字段 | 默认 | 含义 |
|---|---|---|
| `template` | — | 模板序列（仅 ACGT） |
| `topology` | `linear` | `linear` / `circular`（环状允许扩增子与引物跨原点） |
| `target_start` / `target_end` | `0` / `null` | 目标区间 `[start, end)`；`null` 表示不约束。环状模板允许 `end < start` 表示跨原点区间 |
| `product_size_min/max` | `80/300` | 产物长度范围（含引物） |
| `primer_len_min/max` | `18/25` | 引物长度范围 |
| `gc_min/max` | `30/70` | GC 含量上下限（%） |
| `tm_min/max` | `45/65` | 熔解温度范围（°C，模型相对值，见下） |
| `max_dimer_dg` | `-5.0` | 自身/异二聚体允许的最稳定 ΔG（kcal/mol，越负越稳定；候选二聚体 ΔG < 该值即拒绝） |
| `max_hairpin_dg` | `-3.0` | 发夹允许的最稳定 ΔG |
| `max_pairs` | `10` | 返回的引物对数量上限 |
| `seed` | `0` | 随机种子，仅用于并列打散的确定性重排 |
| `reference_library` | `null` | 参考库名；`null` 跳过特异性评估 |
| `max_mismatches` | `3` | 非目标比对允许的最大错配数 |
| `max_3p_consecutive` | `4` | 3' 端连续匹配上限（见判定规则） |

目标区间宽度若大于 `product_size_max`，提交即返回 400（无可行扩增子）。

## 理化模型

- **Tm**：SantaLucia (1998) 最近邻参数，引发项 + 盐校正
  `16.6*log10([Na+])`，`[Na+]=50 mM`，引物浓度 250 nM；自身互补序列附加
  对称熵校正。该模型未计入 Mg²⁺/DMSO，绝对值比 primer3 默认条件低约
  5–8 °C，请按相对尺度使用（默认窗口 45–65 °C 即对应常规 20–25 nt 引物）。
- **退火温度**：`Tm - 5 °C`（经验法则）。
- **二聚体/发夹 ΔG**：在 37 °C 下对两条序列（自身二聚体为序列与其反向
  互补的所有偏移比对；异二聚体同理；发夹为环 ≥ 3 nt 的分子内茎）取最稳定
  的**连续互补区段**的最近邻 ΔG。这是确定性的简化模型：忽略凸起/错配
   duplex、不枚举多个茎，但对"区段越长、GC 越高越稳定"单调，足以支撑
  过滤与排序。
- **连续重复**：最长单核苷酸重复（homopolymer run）。
- **回文末端**：3' 端最后 4–8 nt 若等于自身反向互补（双链回文）则标记。

## 过滤规则（硬约束，按顺序应用）

1. 单引物：`gc_min ≤ GC% ≤ gc_max`，`tm_min ≤ Tm ≤ tm_max`，
   `self_dimer_dg ≥ max_dimer_dg`，`hairpin_dg ≥ max_hairpin_dg`。
2. 引物对：产物长度在范围内、扩增子覆盖目标区间、两引物不重叠、
   `heterodimer_dg ≥ max_dimer_dg`。
3. 非目标命中**不是**硬过滤，而是作为惩罚进入排序（见下）。

## 排序权重

每对引物的罚分 `penalty` 为以下各项之和，`rank_score = -penalty`，
按 `rank_score` 降序返回前 `max_pairs` 条：

| 项 | 权重 | 定义 |
|---|---|---|
| Tm 偏差 | 1.0 | 每条引物 `|Tm − Tm_opt|`，`Tm_opt` 为允许窗口中点 |
| Tm 差 | 2.0 | `|Tm_fwd − Tm_rev|` |
| GC 偏差 | 0.05 | 每条引物 `|GC% − 50|` |
| 自身二聚体 | 1.0 | 每条引物 `−min(ΔG, 0)` |
| 异二聚体 | 1.0 | `−min(ΔG, 0)` |
| 发夹 | 1.0 | 每条引物 `−min(ΔG, 0)` |
| 连续重复 | 2.0 | 每条引物 run ≥ 4 时 `run − 3` |
| 回文 3' 端 | 3.0 | 每条引物命中即加 |
| 非目标命中 | 5.0 | 该对（两条引物合并去重后）每个命中 |
| 产物长度 | 0.01 | `|size − 范围中点|` |

**确定性**：罚分相同者以 `SHA-256(seed | fwd序列 | fwd位置 | rev序列 |
rev位置)` 排序打散。相同输入 + 相同种子 ⇒ 输出逐条一致；不同种子只会
重排完全并列的条目。

## 非目标判定规则

对参考库**每条序列的双链**滑动比对引物全长，一个位点记为命中当且仅当：

- 全长相错配数 `≤ max_mismatches`，**且**
- 3' 端连续匹配数 **严格大于** `max_3p_consecutive`
  （恰好等于上限视为安全——3' 端越稳定非目标延伸风险越高）。

回文位点在正负链坐标相同，只保留一条记录。命中以
`(reference_id, position)` 在引物对内去重后计入罚分。

## 并发、取消与恢复

- **快照隔离**：参考库的每次批量增删先构造新不可变映射再原子替换；
  设计任务在启动时获取一次快照，评估期间并发更新**不会**被读到，
  更不会读到新旧混合状态。
- **分块与内存**：参考序列按 100 kb 窗口（含重叠）扫描；候选对经
  有界堆流式筛选，内存占用与模板产生的候选对总数无关。
- **进度与取消**：`GET /designs/{id}` 返回 `progress.done/total`；
  取消为协作式，在生成、配对流、逐参考扫描处均设检查点。取消后任务
  状态为 `cancelled` 且**不返回任何结果**；所有落盘均经
  临时文件 + fsync + 原子 `rename`，取消或崩溃不会留下部分写入的
  记录或临时文件。
- **重启恢复**：任务记录与参考库均持久化。重启后 `completed` 任务
  结果原样可用；崩溃时处于 `pending/running` 的任务被标记为
  `failed("interrupted by service restart")`，其中间结果**不会**被当作
  最终结果返回，需重新提交。

## 限制

- 热力学为简化确定性模型（见上），不替代 primer3/NTthal 的精算；
  阈值需按本模型尺度标定。
- 候选对评估采用"窗口化精确"策略：先按不含异二聚体项的下界罚分取
  top-K 堆（K 从 `max(100, 10×max_pairs)` 起），仅对窗口计算异二聚体与
  非目标；随后验证"窗口外任何候选的最终罚分都不可能进入前
  `max_pairs`"（两项惩罚均 ≥ 0），不满足则扩大 K 重试，因此在常规
  输入下结果与全量暴力排序**逐条一致**（有测试保证）。对高度简并
  （如大量完全并列）的模板，K 上限为 10000，超过后结果在已评估窗口内
  精确、对窗口外为近似。
- 单任务 CPU 密集阶段为单线程；服务以线程池并发处理多任务
  （默认 2 worker）。
- 参考库全量驻留内存（快照为不可变元组），适合本地/中等规模库；
  不支持超大型基因组的外存索引。
- 模板仅支持 ACGT 字母表；简并碱基会被拒绝。
